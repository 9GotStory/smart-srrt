# เอกสารของระบบเก่า (Legacy)

โฟลเดอร์นี้เก็บเอกสารของ Smart SRRT รุ่นเดิม ซึ่งถูกแทนด้วยการสร้างใหม่ตาม [ADR-0001](../adr/0001-rebuild-on-apps-script-and-sheets.md) เมื่อ 16 พฤศจิกายน 2026

- เอกสารในนี้เป็น**ประวัติ** ไม่ใช่ข้อกำหนดปัจจุบัน และไม่ใช่การอนุญาตให้ทำสิ่งใด
- ข้อกำหนดปัจจุบันอยู่ใน [`../spec.md`](../spec.md), [`../schema.md`](../schema.md), [`../adr/`](../adr/README.md) และ [`../roadmap.md`](../roadmap.md)
- ไฟล์ถูกย้ายมาจาก `docs/` โดยคงโครงโฟลเดอร์เดิม ลิงก์ระหว่างเอกสารในโฟลเดอร์นี้ยังใช้ได้ ส่วนลิงก์ไปยังโค้ด (`src/`, `tests/`, `tools/`) และไปยังไฟล์ที่ยังอยู่ใน `docs/ux/` กับ `docs/implementation/` ชี้ผิดตำแหน่งไปหนึ่งระดับ
- จุดเริ่มอ่านของชุดเดิมคือ [`INDEX.md`](INDEX.md) และ [`features.md`](features.md)
- [`doc-features-historical.md`](doc-features-historical.md) เดิมอยู่ที่ `doc/features.md`

เอกสารเก่า 6 ไฟล์ยังอยู่ที่ `docs/ux/` และ `docs/implementation/` เพราะการทดสอบของระบบเก่าอ่านไฟล์เหล่านั้น จะย้ายมาที่นี่ในช่วงที่ 0 ของ roadmap พร้อมการลบโค้ดเก่า
