# เอกสารของระบบเก่า (Legacy)

โฟลเดอร์นี้เก็บเอกสารของ Smart SRRT รุ่นเดิม ซึ่งถูกแทนด้วยการสร้างใหม่ตาม [ADR-0001](../adr/0001-rebuild-on-apps-script-and-sheets.md) เมื่อ 16 พฤศจิกายน 2026

- เอกสารในนี้เป็น**ประวัติ** ไม่ใช่ข้อกำหนดปัจจุบัน และไม่ใช่การอนุญาตให้ทำสิ่งใด
- ข้อกำหนดปัจจุบันอยู่ใน [`../spec.md`](../spec.md), [`../schema.md`](../schema.md), [`../adr/`](../adr/README.md) และ [`../roadmap.md`](../roadmap.md)
- ไฟล์ถูกย้ายมาจาก `docs/` โดยคงโครงโฟลเดอร์เดิม และไม่ได้แก้เนื้อหา ลิงก์ระหว่างเอกสารที่ย้ายมาด้วยกันยังใช้ได้ ลิงก์ต่อไปนี้ชี้ผิดตำแหน่ง
  - ลิงก์ออกนอกโฟลเดอร์นี้ ไปยังโค้ด (`src/`, `tests/`, `tools/`) ไฟล์ที่ root (`CLAUDE.md`, `README.md`, `package.json`) และ `.github/`
  - ลิงก์ไปยัง 6 ไฟล์ที่ยังอยู่ใน `docs/ux/` กับ `docs/implementation/` และลิงก์จาก 6 ไฟล์นั้นกลับมายังไฟล์ที่ย้ายแล้ว
  - ลิงก์ทั้งหมดใน `doc-features-historical.md`
- จุดเริ่มอ่านของชุดเดิมคือ [`INDEX.md`](INDEX.md) และ [`features.md`](features.md)
- [`doc-features-historical.md`](doc-features-historical.md) เดิมอยู่ที่ `doc/features.md`

เอกสารเก่า 6 ไฟล์ยังอยู่ที่ `docs/ux/` และ `docs/implementation/` เพราะการทดสอบของระบบเก่าอ่านไฟล์เหล่านั้น และ `docs/licenses/` อยู่ที่เดิมเพราะเป็นสัญญาอนุญาตของไลบรารีที่โค้ดเก่าใช้ ทั้งหมดจะย้ายหรือลบในช่วงที่ 0 ของ roadmap พร้อมการลบโค้ดเก่า
