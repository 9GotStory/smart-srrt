# บันทึกการตัดสินใจ (ADR)

แต่ละไฟล์บันทึกการตัดสินใจหลักหนึ่งเรื่อง: ตัดสินอะไร เพราะอะไร ปฏิเสธทางเลือกใด และมีผลอะไรตามมา รายละเอียดของการทำงานและโครงสร้างข้อมูลอยู่ใน [`../spec.md`](../spec.md) และ [`../schema.md`](../schema.md) ซึ่งเป็นแหล่งอ้างอิงเมื่อ ADR กับสองไฟล์นั้นเขียนไม่ตรงกัน

## เมื่อไรควรเพิ่ม ADR

เพิ่มฉบับใหม่เมื่อการตัดสินใจนั้นเปลี่ยนยาก มีทางเลือกจริงที่ถูกปฏิเสธ และคนที่มาทีหลังจะถามว่า "ทำไมถึงทำแบบนี้" การเปลี่ยนการตัดสินใจเดิมให้เพิ่มฉบับใหม่ที่ระบุว่าแทนฉบับใด แล้วแก้สถานะของฉบับเดิมเป็น Superseded

## รูปแบบ

```
# ADR-NNNN: ชื่อเรื่อง

* สถานะ: Proposed | Accepted | Superseded by ADR-NNNN
* วันที่: YYYY-MM-DD

## บริบท
## การตัดสินใจ
## ผลที่ตามมา
## ทางเลือกที่ไม่เลือก
```
