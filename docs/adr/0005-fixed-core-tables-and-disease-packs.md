# ADR-0005: แกนกลางตายตัว และชุดโรคเป็นคำนิยาม

* สถานะ: Accepted (PO อนุมัติผ่านการ Merge ของ PR #276)
* วันที่: 2026-11-16

## บริบท

ระบบเก่ารองรับไข้เลือดออกด้วยโมดูล D331 ที่เพิ่ม 7 ตาราง โค้ดอ่านเขียน และการตรวจสิทธิ์ของตัวเอง ถ้าเพิ่มโรคอื่นด้วยวิธีเดียวกัน ระบบจะโตขึ้นทุกโรค PO ถามว่าการเพิ่มโรคต้องแก้ตารางหลักหรือไม่ และเห็นว่าการแก้ตารางหลักไม่ใช่แนวทางที่ดี

สิ่งที่ต่างกันในแต่ละโรคมีสามอย่าง: ชนิดงาน เป้าเวลา และช่องในแบบบันทึกผล ส่วนโครงของเหตุการณ์เหมือนกันทุกโรค

## การตัดสินใจ

1. ตารางแกนกลาง (`events`, `patients`, `tasks`, `task_results` และตารางประกอบ) ใช้กับทุกโรค และไม่เปลี่ยนเมื่อเพิ่มโรค
2. ช่องข้อมูลอยู่ในแกนกลางได้ก็ต่อเมื่อทุกโรคใช้ช่องนั้น
3. **ชุดโรค** เป็นคำนิยามในโค้ดฝั่ง server ที่ระบุชนิดงาน เป้าเวลา แบบบันทึกผล และรอบการทำงาน
4. ค่าของช่องเฉพาะโรคเก็บใน `task_results.data_json` พร้อม `form_code` และ `form_version` server ตรวจค่าตามคำนิยามก่อนบันทึก
5. ผู้ดูแลแก้ได้เฉพาะการเปิดปิดชุดโรค เป้าเวลา และจำนวนวันของรอบการทำงาน ผ่านหน้าตั้งค่า
6. รุ่นแรกมีชุดไข้เลือดออกชุดเดียว

เพิ่มเติมเมื่อ 2026-11-17 จากการลงรายละเอียดฟีเจอร์ที่ 8: ชุดของรุ่นแรกเปลี่ยนชื่อเป็นชุดโรคติดต่อนำโดยยุงลาย เพราะมาตรการที่ชุดทำตามใช้กับสามโรค และผู้ดูแลเลือกได้ด้วยว่าโรคใดใช้ชุดใดในหน้ารายการโรค ([`spec.md` ข้อ 5](../spec.md#5-ชุดโรค)) ข้อ 1–4 ไม่เปลี่ยน

## ผลที่ตามมา

- การเพิ่มโรคคือการเพิ่มคำนิยามหนึ่งชุดผ่าน PR ไม่มีแท็บหรือคอลัมน์ใหม่ และไม่แตะข้อมูลเดิม
- สถานะ ตัวชี้วัด และสรุปของทุกโรคอ่านจากตารางชุดเดียวกัน
- เมื่อเปิดไฟล์ Sheet ดูตรง ๆ ช่องเฉพาะโรคอยู่รวมในเซลล์เดียว อ่านยากกว่าแบบแยกคอลัมน์ ผู้ใช้ดูผ่านหน้าจอ และไฟล์ที่ส่งออกแตกเป็นคอลัมน์ให้
- ความถูกต้องของช่องเฉพาะโรคขึ้นกับการตรวจของ server ทั้งหมด จึงต้องมีการทดสอบครอบคลุมทุกแบบบันทึก
- การแก้ช่องของแบบบันทึกต้องเพิ่มรุ่นของแบบ เพื่อให้แถวเก่ายังอ่านได้
- ต้องมีการทดสอบที่เพิ่มชุดโรคสมมติอีกชุด เพื่อพิสูจน์ว่าข้อ 1 เป็นจริง

## ทางเลือกที่ไม่เลือก

- **เพิ่มคอลัมน์เฉพาะโรคในตารางหลัก** ไม่เลือก โครงสร้างตารางเปลี่ยนทุกครั้งที่เพิ่มโรค
- **เพิ่มแท็บชุดใหม่ต่อโรค แบบ D331** ไม่เลือก ทุกโรคต้องมีโค้ดอ่านเขียนและการตรวจสิทธิ์ชุดใหม่
- **หน้าจอให้ผู้ดูแลสร้างแบบบันทึกเอง** ไม่เลือกในรุ่นแรก เป็นงานใหญ่ การตั้งค่าผิดทำให้ข้อมูลเสียได้ และโรคที่ต้องมีชุดเฉพาะในระดับอำเภอมีไม่กี่โรค
