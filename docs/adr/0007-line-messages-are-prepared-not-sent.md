# ADR-0007: ระบบเตรียมข้อความ LINE ผู้ใช้ส่งเอง

* สถานะ: Accepted (PO อนุมัติผ่านการ Merge ของ PR #276)
* วันที่: 2026-11-16

## บริบท

สสอ. และ รพ.สต. ประสานงานกันผ่าน LINE ระบบเก่าไม่มีส่วนที่เกี่ยวกับ LINE ผู้ใช้ต้องพิมพ์ข้อความเอง แล้วกลับมาบันทึกในระบบ

ปรับเมื่อ 2026-11-17: ฉบับแรกเขียนว่าประสานงานผ่านกลุ่ม LINE PO ยืนยันว่า สสอ. แจ้งเจ้าหน้าที่ของหน่วยบริการที่รับผิดชอบเป็นรายคน และไม่ใช้กลุ่ม การตัดสินใจทั้งห้าข้อไม่เปลี่ยน รายละเอียดของข้อความอยู่ใน [spec ข้อ 4](../spec.md#ข้อความ-line)

LINE Notify ปิดบริการเมื่อ 31 มีนาคม 2025 การให้ระบบส่งข้อความเองต้องใช้ LINE Messaging API ผ่าน LINE Official Account ซึ่งต้องตั้งค่าเพิ่ม มีโควตาข้อความ และส่งข้อมูลออกไปยังบริการภายนอกโดยไม่มีคนตรวจ

## การตัดสินใจ

1. ระบบสร้างข้อความให้ ผู้ใช้กด "คัดลอก" หรือ "เปิด LINE" แล้วเลือกผู้รับและส่งเอง
2. ข้อความมีโรค หมู่บ้าน งานที่ต้องทำ กำหนดเสร็จ และลิงก์ไปที่งานหรือเหตุการณ์
3. ข้อความไม่มีชื่อผู้ป่วยและบ้านเลขที่
4. ระบบเตรียมข้อความทั้งสองทาง: ผู้ดูแลถึง รพ.สต. เมื่อมอบหมายหรือติดตามงาน และ รพ.สต. ถึง สสอ. เมื่อแจ้งเหตุการณ์หรือบันทึกผล
5. ระบบบันทึกเวลาที่แจ้ง รพ.สต. เมื่อผู้ดูแลกดยืนยันว่าส่งแล้ว และผู้ดูแลแก้ค่านี้ได้ ชุดไข้เลือดออกใช้ค่านี้เป็นจุดสิ้นสุดของเป้าแจ้ง รพ.สต. และเป็นจุดเริ่มของเป้าควบคุมโรค

## ผลที่ตามมา

- ไม่ต้องมี LINE Official Account ไม่มีค่าใช้จ่าย และไม่มีกุญแจของบริการภายนอกให้ดูแล
- ผู้ใช้เห็นข้อความทุกครั้งก่อนส่ง
- ระบบไม่รู้ว่าข้อความถูกส่งจริงหรือไม่ เวลาที่แจ้ง รพ.สต. เป็นเวลาที่ผู้ดูแลยืนยัน ไม่ใช่เวลาที่ LINE ส่ง
- ผู้ดูแลไม่ได้รับการแจ้งเตือนอัตโนมัติเมื่อ รพ.สต. แจ้งเหตุการณ์ ต้องอาศัยข้อความ LINE จาก รพ.สต. หรือการเปิดหน้า "งานวันนี้"
- การกดเปิด LINE จากหน้าเว็บบนมือถือยังไม่ได้ทดสอบ ต้องทดสอบบนมือถือจริงในช่วงที่ 3 ของ [roadmap](../roadmap.md) LINE จัดทำเอกสารของ URL ที่เปิดหน้าเลือกผู้รับพร้อมข้อความไว้ และรองรับเฉพาะ iOS กับ Android ([ผลการค้นเรื่องข้อความ LINE](../research/line-message-facts.md) ส่วนที่ 2)

## ทางเลือกที่ไม่เลือก

- **ส่งอัตโนมัติด้วย LINE Messaging API** เลื่อนไปรุ่นถัดไป ด้วยเหตุผลในบริบท
- **แจ้งเตือนทางอีเมล** เลื่อนไปรุ่นถัดไป ช่องทางที่ผู้ใช้เปิดดูจริงคือ LINE
- **ใส่ชื่อผู้ป่วยในข้อความ** ไม่เลือก ข้อความที่ส่งแล้วอยู่นอกการควบคุมของระบบและถูกส่งต่อได้ และแนวทางการใช้สื่อสังคมออนไลน์ของผู้ปฏิบัติงานด้านสุขภาพ พ.ศ. 2559 ให้ลบข้อมูลระบุตัวผู้ป่วยก่อนส่ง เหตุผลนี้ใช้กับแชตรายคนเท่ากับกลุ่ม ([ผลการค้นเรื่องข้อความ LINE](../research/line-message-facts.md) ส่วนที่ 9)
