# Smart SRRT

ระบบติดตามเหตุการณ์โรคและภัยสุขภาพสำหรับสำนักงานสาธารณสุขอำเภอ (สสอ.) หนึ่งแห่ง ใช้ตั้งแต่รับแจ้งข่าว ตรวจสอบ มอบหมายงานให้ รพ.สต. ลงพื้นที่ รับผลกลับ ติดตาม จนปิดเหตุการณ์

> **สถานะ — 16 พฤศจิกายน 2026:** ระบบกำลังถูกสร้างใหม่ทั้งหมดเป็น **v2** Product Owner อนุมัติเอกสารของ v2 แล้ว และยังไม่มีโค้ดของ v2 ใน repository โค้ดที่มีอยู่ตอนนี้เป็นของระบบเก่า ซึ่งหยุดพัฒนาแล้ว

ระบบนี้ไม่ใช่ระบบเวชระเบียน ไม่ใช่เครื่องมือวินิจฉัย และไม่ได้เชื่อมกับระบบรายงานของกระทรวง

## v2 โดยย่อ

- **ผู้ใช้ 3 แบบ:** ผู้ดูแล (สสอ.) รพ.สต. ที่เห็นเฉพาะงานของหน่วยตน และผู้ดู
- **เหตุการณ์เดียว มีขั้นตอนชัดเจน:** รับแจ้ง → ตรวจสอบข่าว → ประเมินเกณฑ์ → มอบหมายงาน → รับผล → ติดตาม → ปิด
- **ประสานงานผ่าน LINE:** ระบบเตรียมข้อความพร้อมลิงก์ไปที่งาน ผู้ใช้กดส่งเอง
- **ชุดโรค:** ขั้นตอนเฉพาะโรคเป็นคำนิยามที่เพิ่มได้โดยไม่แก้ตาราง รุ่นแรกมีชุดไข้เลือดออกตามมาตรการ 3-3-1-7-14-21-28
- **เข้าสู่ระบบด้วย Google:** ผู้ดูแลกำหนดว่าอีเมลใดเข้าได้
- **เทคโนโลยี:** หน้าเว็บ React บน Cloudflare Pages, Google Apps Script เป็น API, Google Sheets เป็นฐานข้อมูล

## ระบบเก่า

โค้ดใน `src/`, `tests/`, `tools/` และไฟล์ One-Click ที่ root เป็นของระบบเก่า จะถูกลบออกจากสาขาหลักในช่วงที่ 0 ของ [roadmap](docs/roadmap.md) หลังทำ tag `legacy-v1` เอกสารของระบบเก่าอยู่ใน [`docs/legacy/`](docs/legacy/README.md)

ระหว่างนี้ CI ยังรันการตรวจของระบบเก่า คำสั่งอยู่ใน `package.json` และต้องใช้ Node.js 20 ขึ้นไป

```bash
npm ci --ignore-scripts
npm test
```

## ข้อมูลและความเป็นส่วนตัว

Repository นี้เป็นสาธารณะ ไม่มีข้อมูลเหตุการณ์จริง ข้อมูลผู้ป่วย ID ของไฟล์หรือ deployment และกุญแจใด ๆ การพัฒนาและการทดสอบใช้ข้อมูลสมมติเท่านั้น หลักการด้านข้อมูลผู้ป่วยอยู่ใน [ADR-0006](docs/adr/0006-patient-data-and-public-disclosure.md)
