คู่มือติดตั้ง Smart SRRT Dashboard & AI Reporter
รุ่น One-Click Install + Village Master + Web Logo Upload
Version 2026.08.02

ไฟล์ในชุด
1. Code_Smart_SRRT_OneClick.gs   = โค้ดฝั่ง Google Apps Script
2. Index_Smart_SRRT_OneClick.html = หน้าเว็บ
3. AreaMaster_Template.csv       = ตัวอย่างไฟล์นำเข้าข้อมูลหมู่บ้าน

========================================
A. ติดตั้งระบบใหม่
========================================
1. สร้าง Google Sheet ใหม่ 1 ไฟล์
2. ไปที่ Extensions > Apps Script
3. เปิดไฟล์ Code.gs เดิม ลบโค้ดเดิม แล้ววางโค้ดจาก Code_Smart_SRRT_OneClick.gs
4. กดเครื่องหมาย + > HTML ตั้งชื่อไฟล์ว่า Index
5. วางโค้ดจาก Index_Smart_SRRT_OneClick.html ลงในไฟล์ Index
6. กด Save
7. เลือกฟังก์ชัน installSmartSRRT แล้วกด Run เพียงครั้งเดียว
8. อนุญาตสิทธิ์ Google Sheet, Drive และ Documents
9. คัดลอก Email และรหัสผ่าน Super Admin ที่แสดงหลังติดตั้ง
10. ไปที่ Deploy > New deployment > Web app
    - Execute as: Me
    - Who has access: เลือกตามนโยบายหน่วยงาน
11. เปิด URL ของ Web app และเข้าสู่ระบบ

ระบบจะสร้างอัตโนมัติ
- MainData
- UserAccounts
- SystemSettings
- MasterData
- AreaMaster
- ContentLibrary
- AuditLogs
- VisitLogs
- โฟลเดอร์หลัก Smart SRRT
- โฟลเดอร์รายงานสอบสวนโรค
- โฟลเดอร์โลโก้
- Google Docs Template รายงานสอบสวนโรคเบื้องต้น

========================================
B. ตั้งค่าผ่านหน้า Admin
========================================
หลังเข้าสู่ระบบ เลือกเมนู “การจัดการระบบ”

ตั้งค่าได้โดยไม่ต้องเปิดแก้ Google Sheet
- ชื่อระบบ
- คำอธิบายระบบ
- ชื่อหน่วยงานและข้อมูลติดต่อ
- ข้อความประกาศ
- สีหลักและสีรอง
- เปิด/ปิดการบันทึกข้อมูล
- เปิด/ปิดการสมัครผู้ใช้
- อัปโหลดและเปลี่ยนโลโก้จากหน้าเว็บ
- Gemini API Key และ Gemini Model
- Google Docs Template ID
- Report Folder ID
- ผู้ใช้งานและสิทธิ์
- ประกาศ/แนวทาง/คู่มือ
- ข้อมูลจังหวัด อำเภอ ตำบล หมู่ ชื่อหมู่บ้าน และรหัสหมู่บ้าน

โลโก้รองรับ PNG, JPG/JPEG และ WEBP ขนาดไม่เกิน 3 MB
หมายเหตุ: หากหน่วยงานปิดการแชร์ไฟล์ Drive ภายนอก โลโก้อาจแสดงเฉพาะผู้ที่มีสิทธิ์เข้าถึงไฟล์

========================================
C. นำเข้าข้อมูลหมู่บ้าน
========================================
1. เตรียม Excel หรือ CSV โดยมีหัวคอลัมน์
   จังหวัด, อำเภอ, ตำบล, หมู่, ชื่อหมู่บ้าน, รหัสหมู่บ้าน
2. เข้าหน้า Admin > จัดการข้อมูลพื้นที่ระดับหมู่บ้าน
3. กด Import Excel/CSV
4. ระบบเพิ่มรายการใหม่และอัปเดตรายการเดิมที่ตรงกัน

========================================
D. อัปเกรดจากระบบเดิม
========================================
1. สำรอง Google Sheet และโค้ดเดิมก่อน
2. แทนที่ Code.gs และ Index ด้วยไฟล์รุ่นนี้
3. Run installSmartSRRT() 1 ครั้ง
4. ฟังก์ชันติดตั้งสามารถรันซ้ำได้ โดยจะสร้างเฉพาะชีต คอลัมน์ โฟลเดอร์ หรือ Template ที่ขาด
5. ข้อมูลเดิม 28 คอลัมน์ยังคงอยู่ ระบบเพิ่มท้ายตาราง 2 คอลัมน์ ได้แก่ ชื่อหมู่บ้าน และรหัสหมู่บ้าน
6. Deploy เวอร์ชันใหม่ โดยเลือก Manage deployments > Edit > New version

========================================
E. รหัสผ่านผู้ดูแล
========================================
- ระบบสร้างรหัสผ่าน Super Admin แบบสุ่มในครั้งแรก
- ควรเปลี่ยนรหัสผ่านทันทีจากหน้า Admin > จัดการผู้ใช้งาน
- หากลืมรหัส ให้เปิด Google Sheet แล้วใช้เมนู Smart SRRT > รีเซ็ตรหัส Super Admin
  หรือ Run ฟังก์ชัน resetSuperAdminPassword() ใน Apps Script

========================================
F. การตั้งค่า AI Reporter
========================================
- ระบบสร้าง Template และโฟลเดอร์รายงานให้อัตโนมัติ
- ใส่ Gemini API Key ผ่านหน้า Admin เท่านั้น
- ค่า Gemini Model แนะนำให้เริ่มจาก AUTO
- Template ที่สร้างอัตโนมัติมีโครงสร้าง บันทึกข้อความ, ชื่อเรื่อง, ผลวิเคราะห์จาก AI,
  ส่วนลงชื่อผู้รายงาน และตารางรายชื่อทีมสอบสวนโรค

========================================
G. การตรวจสอบ/ซ่อมระบบ
========================================
หน้า Admin มีปุ่ม “ตรวจสอบ/ซ่อมระบบอัตโนมัติ”
ใช้เมื่อชีต โฟลเดอร์ หรือ Template ถูกลบ/ย้าย ระบบจะตรวจสอบและสร้างส่วนที่ขาดใหม่โดยไม่ลบข้อมูลเหตุการณ์เดิม
